# ТЗ: текстовая выноска Quick Edit по референсу

**Дата:** 2026-10-06
**Статус:** реализовано, требуется ручная проверка в приложении

## Описание задачи

Привести текстовую выноску к правым частям предоставленных пользователем сравнений: крупная жёлтая плашка, центрированный полужирный текст, два редактируемых хвоста и изменение размера плашки.

## Затронутые разделы

- Quick Edit на снимке: создание и редактирование текстовой выноски.
- Copy/PNG: экспорт той же геометрии без служебных маркеров.

Проект — настольное приложение. `.Codex/analyst.md`, веб-URL и Playwright-разделов нет. Для визуальной проверки создан локальный образец `Verification/artifacts/callout-reference.png`.

## Текущее поведение до доработки

`Services/QuickEditInkStore.cs` создавал плашку примерно 120×34, фиксировал основания обоих хвостов снизу и перемещал кончики вместе с плашкой. `Services/QuickEditCalloutRenderer.cs` накладывал рамку поверх оснований хвостов, оставляя шов.

## Ожидаемое поведение

Плашка начинается примерно с 180×50, меняет размер восемью белыми маркерами. Две зелёные точки оснований исходно находятся на нижней рамке и могут перемещаться по любым сторонам. Кончики хвостов закреплены за координатами снимка и не сдвигаются при перемещении или изменении размера плашки. Контур у основания прерывается. Текст центрирован. Подробная геометрия утверждена в `docs/superpowers/specs/2026-10-06-quick-edit-callout-reference-design.md`.

## Технические детали

### Backend

Сервер, API и БД не затронуты.

### Frontend

- `Services/QuickEditInkStore.cs` — размеры, якоря на контуре, независимые кончики, resize, undo.
- `Services/QuickEditCalloutGeometry.cs` — проекция якоря на сторону и треугольники хвостов.
- `Services/QuickEditCalloutRenderer.cs` — единый силуэт без шва, центрированный текст.
- При масштабе дисплея 125% рамка была больше маркеров: координата начала преобразовывалась через `toLocal`, а ширина и высота оставались в экранных пикселях. Теперь обе противоположные точки плашки проходят через одно преобразование; регрессионная проверка моделирует масштаб 80%.
- После расширения плашки основание хвоста оставалось фиксированным (20 px). Теперь его ширина пропорциональна длине стороны с минимальным размером и ограничением около углов; проверка сравнивает плашки шириной 180 и 540 px.
- Видео `Video_2026-10-06_134103.mp4` показало отдельные зелёные точки на обоих концах основания каждого вытянутого хвоста. Теперь каждый конец хранит собственную нормализованную позицию на контуре и перетаскивается независимо; проверены перемещение края на верхнюю грань и последовательный Ctrl+Z. У ещё не вытянутого хвоста остаётся одна стартовая точка.
- `Overlay/OverlaySurface.cs` — белые и зелёные маркеры.
- `Services/RectToolsInputController.cs` — обработка перетаскивания сразу после завершения ввода текста.
- `Services/QuickEditImageComposer.cs` — экспорт через общий renderer.
- `Verification/Program.cs` — проверки геометрии, перемещения, размера, отмены и экспорта.

### Редактирование текста (уточнение 2026-10-06)

Повторный двойной щелчок по существующей плашке открывает редактирование с кареткой в конце. Прежний редактор был нарисованной строкой с символом `|`: выделить часть текста и поставить каретку мышью было невозможно; длинная строка расширяла плашку за экран. Внутри плашки должен работать настоящий WPF `TextBox` с выделением мышью и клавиатурой, переносом строк и прокруткой к каретке. Его текст синхронизируется с `QuickEditInkStore`, поэтому отмена изменения остаётся доступной через Ctrl+Z после завершения ввода. Ширина плашки больше не зависит от длины строки. Значок текстового инструмента — прямоугольная выноска с тремя точками по предоставленному изображению. Затронуты `Overlay/OverlayWindow.cs`, `Overlay/OverlaySurface.cs`, `Services/QuickEditInkStore.cs`, `Services/QuickEditCalloutRenderer.cs`, `Verification/Program.cs`.

## Критерии приёмки

- [x] Размер по умолчанию не меньше 180×50, текст центрирован и полужирный.
- [x] Два хвоста можно вытянуть независимо; основания могут оказаться на боковой/верхней стороне.
- [x] Экспортированный хвост не пересекается линией рамки у основания.
- [x] Изменение размера и перемещение плашки сохраняют координаты кончиков.
- [x] Размер меняется белыми маркерами и отменяется Ctrl+Z.
- [ ] Проверить жесты и внешний вид вручную в работающем приложении.
